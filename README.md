### 👨‍💻 Sobre Mim

Tenho **20 anos** e opero na interseção entre desenvolvimento backend e inteligência artificial. Minha filosofia é **AI-First**: não apenas escrevo código, eu crio sistemas que escrevem, corrigem e otimizam processos.

* 🔭 **Foco atual:** Desenvolvimento de arquiteturas complexas para Bots de Discord e agentes autônomos.
* 💡 **Superpoder:** Transformar tarefas repetitivas em fluxos automatizados de alta performance.
* 🧠 **Metodologia:** Utilizo LLMs no core do meu workflow para refatoração, *debugging* preditivo e *Prompt Engineering* avançado.
